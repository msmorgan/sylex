# A counter's kind ("charge", "+1/+1") premodifying *counter*, with the article's form following the kind's pronunciation
+NounPhrase a charge counter => Nominal "charge counter"
+NounPhrase charge counters => Nominal "charge counters"
+NounPhrase a reach counter or a vigilance counter => NounPhrase "a reach counter"; NounPhrase "a vigilance counter"
+NounPhrase a +1/+1 counter => Nominal "+1/+1 counter"
+NounPhrase a -1/-1 counter => Nominal "-1/-1 counter"
+NounPhrase a +1/+0 counter
+NounPhrase a -0/-1 counter
+NounPhrase a -0/-2 counter
+NounPhrase a -1/-0 counter
+NounPhrase a +1/+1 or -1/-1 counter => Kind "+1/+1 or -1/-1" as Modifier of counter; readings 1
+NounPhrase a +2/+0, +1/+1, or +0/+2 counter => Kind "+2/+0, +1/+1, or +0/+2" as Modifier of counter; readings 1
# Slash-measure nominals coordinate under a shared determiner when the final conjunct is not *counter*.
+NounPhrase a 2/2 or 3/3 => Nominal "2/2 or 3/3"; readings 1
+NounPhrase a white 2/2 and blue 3/3 => Nominal "white 2/2"; Nominal "blue 3/3" || Nominal "2/2 and blue 3/3"; readings 2
# A kind name premodifies *counter* as its kind; where *time* ends a Nominal and *counters* begins a clause, they are no kind and counter.
+ Sacrifice a Thrull: Put three time counters on this Aura. => Nominal "time counters" head counter; Kind "time" as Modifier of counter; readings 1
+ Whenever one or more counters are put on a creature you control, if it's the first time counters have been put on that creature this turn, put a +1/+1 counter on that creature. => PrepositionPhrase "if it's the first time counters have been put on that creature this turn" as Adjunct of put; Clause "counters have been put on that creature this turn"; RelativeClause "counters have been put on that creature this turn" as Modifier of time gap "first time"; !Nominal "time counters"
# A counter's kind is the one premodifier *counter* takes in its place: a measure or keyword there is no general premodifier, only a keyword a keyword counter can be is a kind [CR#122.1b], and a kind name stands nowhere else (english.md §3).
+ <card=Travel Preparations> Put a +1/+1 counter on each of up to two target creatures. => Kind "+1/+1" as Modifier of counter; readings 1
+ <card=Mai, Jaded Edge> Exhaust — {3}: Put a double strike counter on Mai. => Kind "double strike" as Modifier of counter; readings 1
+ <card=Bomb Squad> {T}: Put a fuse counter on target creature. => Kind "fuse" as Modifier of counter; !KeywordPhrase "fuse"; readings 1
+ <card=Craft with Pride> Create a Treasure token. => NounPhrase "a Treasure token" as Object of create; readings 1
+ <card=Under the Skin> Manifest dread. => !Name "dread"; readings 1
# A slash measure after *of* is a choice's option only, never the counted set of *number* standing apart from *counter*.
+ <card=Molten Hydra> {T}, Remove all +1/+1 counters from this creature: It deals damage to any target equal to the number of +1/+1 counters removed this way. => NounPhrase "the number of +1/+1 counters removed this way"; !MeasureNounPhrase "+1/+1"#2
